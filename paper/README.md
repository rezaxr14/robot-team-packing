# Paper: attributable failures in language-coordinated robot teams (working title)

Status: full draft, 21 pages. Contains NO trained-model, benchmark or physics result; every such cell is a red `\todo{pending}`.
Authors, title, venue, system name (`\sys`), compute notes are placeholders flagged in red.

## Layout
- `main.tex`, `sections/*.tex`, `refs.bib` (each entry's `note` is `verified: ...` or `TODO-verify`)
- `figures/svg|pdf`: 12 figures built by `scripts/build_diagrams.py` (vector, audited)
- `generated/`: `figdata.json` and `fixture.json` (recorded from the project code), number macros, tables, `*.pending.json`
- `scripts/`: collectors (need the `robot_team` project), figure builder + two audits, `build_paper.py`, `verify_paper.py`
- `OPEN_ITEMS.md`: what is still open (regenerated by `verify_paper.py`)

## Rebuild
```
python scripts/collect_figdata.py --project ../robot_team
python scripts/collect_fixture.py --project ../robot_team
python scripts/build_diagrams.py && python scripts/audit_diagram_text.py && python scripts/audit_diagram_arrows.py
python scripts/build_paper.py
pdflatex main && bibtex main && pdflatex main && pdflatex main
python scripts/verify_paper.py
```
When results exist, put the bundle in `results/` (`reports/**/records.jsonl`, `reports/credit/credit.json`) or set `RTP_RESULTS`; `build_paper.py` and `build_diagrams.py` then fill the tables and `fig_results` and nothing else needs editing.
