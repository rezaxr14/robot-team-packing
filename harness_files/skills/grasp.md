id: grasp
type: skill
keywords: grasp force slip crush payload
---
grasp(obj, force): force must exceed the slip threshold (about 4 + 6*mass newtons) and stay below the crush limit (about 30 - 22*fragility). Payload per arm is 2.5 kg. If a grasp slips, raise force using the measured weight from TOUCH; if it crushes, lower force.
